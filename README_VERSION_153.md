# PhysioSentinel Gait Version 153

Versión centrada en dos objetivos: exportación completa y reproducible del análisis musculoesquelético 3D, y separación cuantitativa de inclinación del tronco, traslación tronco-pelvis y desplazamiento del COM/BOS.

La Pestaña 13 publica sus tablas en `session_state`, y la Pestaña 8 las incorpora automáticamente al ZIP con nombres descriptivos. Las nuevas variables de tronco son proyectadas 2D y deben interpretarse según la calidad/orientación de la cámara.
