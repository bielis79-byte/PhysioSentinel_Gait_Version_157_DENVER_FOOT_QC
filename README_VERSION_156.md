# Version 156

Base: Version 155.

Esta versión repara exclusivamente la regresión de interfaz que dejó vacía la Pestaña 8. El resto de la arquitectura anatómica y de análisis se conserva.

Para validar en Streamlit:
1. Abrir/cargar una sesión con resultados.
2. Entrar en `8 · Exportar / Descargar`.
3. Verificar que aparecen `Resultados CSV`, `Informes TXT`, vídeos disponibles y `📦 Descargar TODO en ZIP`.
4. Descargar el ZIP y comprobar el manifiesto y las carpetas de Pestañas 4, 5, 9, 10, 11, 12 y 13 según los datos disponibles en sesión.
